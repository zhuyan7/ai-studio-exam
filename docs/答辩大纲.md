## 第 2 页：问题背景

**讲稿要点（廖妍讲）：**
- 通用大模型当助教，效果停留在「这道题答案是什么」——缺少重复练习与进度跟踪
- 真正的学习闭环：记下错题 → 针对薄弱点再练 → 看到进度 → 持续改进
- 本项目把范围收窄到 Python 一门课，让知识点可组织、错题可归类、练习落在薄弱点上
- **核心差异点**：编程题能真实运行判对错，不靠模型猜

## 第 3 页：产品定位与功能总览

**讲稿要点（左施英讲）：**
- 面向《Python 程序设计》课程的闭环学习助教，非通用问答机器人
- 四大功能模块：
  - ② 错题录入与自动归类（LLM 归类到知识点）
  - ③ 薄弱点针对性练习（按薄弱点出题 → 作答 → 真实运行判对错）
  - ④ 学习进度与掌握度（各知识点正确率、薄弱点排序）
  - ① 知识点问答（加分项，限定学科范围）
- 闭环示意：错题 → 归类 → 薄弱点 → 出题 → 判题 → 进度 → 再练

---

## 第 4 页：技术方案

**讲稿要点（朱妍讲）：**
- 后端：Python 标准库（http.server + sqlite3 + urllib），**零第三方依赖**
- 大模型：DeepSeek（OpenAI 兼容接口，国内直连，错题归类/出题/问答）
- 判题引擎：subprocess 真实运行学生代码 + 测试用例逐条 eval 比对，对错确定不靠 LLM
- 存储：SQLite，开箱即用，20 个 Python 知识点 + 8 道示例题种子数据
- 前端：原生 HTML/CSS/JS 单页，零构建零依赖
- 架构图：浏览器 → http.server → (SQLite / DeepSeek API / subprocess 判题)

---

## 第 5 页：核心亮点——真实判题

**讲稿要点（朱妍讲，重点页）：**
- 学科优势：Python 代码可真实运行，判对错确定，不依赖 LLM 猜测
- 判题流程：学生提交函数定义 + 题目测试用例（调用表达式+期望值）→ 拼成脚本 → subprocess 运行 → 逐条 eval 比对
- 安全：设 5 秒超时防死循环
- 自检：6 个测试用例覆盖正常/超时/异常，全部通过
- 对比：通用大模型判题靠猜，可能把错的判对；本项目真实运行，对错可信

## 第 7 页：知识点体系设计

**讲稿要点（廖妍讲）：**
- 自建 Python 知识点树，20 个知识点，分 5 大类：
  - 基础语法（变量/运算符/输入输出/条件/循环）
  - 数据结构（列表/元组/字典/集合/字符串）
  - 函数（定义/参数/返回值/递归/lambda）
  - 面向对象（类/继承）
  - 异常与文件（异常处理/文件读写）
- 每个知识点有描述 + 关联知识点，错题归类到此体系上
- 8 道示例编程题覆盖主要知识点，每题带测试用例，评审无需自行构造即可跑通
